# Simon Game 🎮✨  

### Description 📝  
Simon Game is a fun and interactive memory game where players must repeat a sequence of colors and sounds that grow increasingly complex. It's a test of memory and attention to detail! 🧠🎨  

---

### [Play the Game Here! 🌐](https://samnang1111.github.io/Simon-Game/)

---

### How to Play 📜  
1. 🟢 Click the **"Play"** button to begin the game.  
2. 🌈 Watch the sequence of lights and listen to the sounds.  
3. 🖱️ Repeat the sequence in the correct order by clicking the corresponding buttons.  
4. ➕ Each round, the sequence gets longer.  
5. ❌ If you click the wrong button, the game resets. Try again!
